01 問題意識與理論地基 02 / 09

開發前先想清楚：給了 AI 工具，學生就會用嗎？

能力取向 × 自我決定理論（SDT）

  • 可用 ≠ 能力擴展：提供 AI 接入（Access）只是起點，重點是能否真正轉化為學生的實質學習自由（能力取向 Capability Approach；Sen）。
  • 三大內在動機需求（SDT）：
    ① 自主性（Autonomy）：能依自己的步調探索。
    ② 勝任感（Competence）：獲得清晰回饋而非挫敗。
    ③ 關聯感（Relatedness）：感到被理解與社群連結。

隱形門檻：別假設所有學生都一樣

  • 心理資源落差：低自尊、低心理韌性（Resilience）、高神經質的學生更容易產生科技壓力，不敢在 AI 面前試錯（Mourelatos & Liontou, 2026; N = 748）。
  • 決策風格差異：18–29 歲年輕族群與「直覺型決策者」容易略過繁瑣說明，直接憑直覺操作（Klütsch et al., 2026; N = 209）。
  • 世代與任務偏好：20–30 歲在創意任務信任度較高、40–50 歲在創意任務不適感較高（Lee et al., 2027; N = 129）。
教育 AI 設計第一原則：放棄「一體適用（One-Size-Fits-All）」的單一介面，為低自信或直覺型學習者提供低風險的「安全練習沙盒」與清楚鷹架。

02 快速建構架構 03 / 09

不用從頭訓練模型：Multi-Agent 快速組裝管線

借鏡 EmotiStage（Wang et al., 2026, ICMI '26）的多代理架構，用結構化 JSON 串接現成 API 即可快速落地：

1

引導探索代理

用 GPT-4o 進行 3–4 輪引導對話，嚴格限制每輪只問一題（One-question-per-turn），避免學生對話疲乏。

2

結構化分析代理

將對話濃縮為共用的 JSON 中繼表徵（故事摘要＋雙層標籤：持續性主軸情緒 vs. 衝突次要情緒），供下游共用。

3

多模態並行生成

文字腳本、背景圖像（DALL-E 3）、聲學參數／音訊（LeVo）與預設動畫並行產生，縮短等待時間。

4

輕量前端合成

使用 Vue.js + Web Audio API / CSS 圖層合成，不需複雜 3D 引擎即可呈現反思舞台。

教育場域改裝範例：將「情緒劇場」替換為「歷史情境辯論台」或「實驗錯誤重演室」——學生先對話釐清觀點，再調整參數，最後退居觀眾席觀察兩個 AI 角色對質。

02 多模態與控制權設計 04 / 09

多模態整合與「把什麼控制權留給學生」

基於形式的多模態整合（Form-Grounded）

先找一個學生原本就懂的複合文化形式（如劇場、實驗室筆記），自然決定各模態分工（Wang et al., 2026）：

  • 背景圖像 → 建立學習情境與脈絡氛圍。
  • 聲音與歌詞 → 傳遞情感基調與節奏記憶。
  • 虛擬角色對話 → 把抽象衝突具象化為可觀察的辯論。

控制權委派邊界（Artistic Delegation）

  • 保留給學生（意義校準）：讓學生決定核心問題與調整高階參數（EmotiStage 中 12/13 人主動調整 BPM/音色來自我校準）。
  • 委派給 AI（技術渲染）：自動產出美編、配樂與動畫，避免學生陷入「操作工具的焦慮」而忘記學習思考。
  • 適度失控的價值：讓學生退居「觀眾（Spectator）」，產生自我抽離（Self-Distancing），看見原本忽略的盲點。

03 對話策略與錯誤復原 05 / 09

03 外觀、語氣與透明倫理 06 / 09

虛擬助教的外觀、阿諛奉承與「AI 身分揭露」

1. 避開恐怖谷效應

別追求照片級逼真真人！

  • 採用風格化／卡通感 3D 或 2D 化身（Kober et al., 2026; Wang et al., 2026）。
  • 加入微幅眨眼與呼吸動作即可提升親切感，同時保留「人工感」避免不適（Uncanny Valley）。

2. 控制 LLM 阿諛奉承

Sycophancy 會傷及教育公信力：

  • 過度附和學生錯誤答案會破壞學習與信任。
  • 但需注意：Prompt 過度抑制熱情會讓 AI 語氣在 VADER 分析中比真人更冷淡（Kober et al., 2026），需保留適度鼓勵。

3. 身分透明度的心理代價

盲測與明測的驚人對比（Kober et al., 2026; N = 42）：

  • 不知情時 10/21 人分不出 AI 與真人；一旦知情，正向情感與社會臨場感顯著下降（p < .01）。
  • 對策：倫理上必須明確標示 AI 身分，並靠「結構化同理引導」彌補心理距離。

04 教育資料與隱私設計 07 / 09

讓學生真正看懂 AI 隱私風險：兩階段知情推力

學生常因通知疲乏或想趕快用工具而忽略個資授權（隱私悖論 Privacy Paradox）。參考 Klütsch et al.（2026）設計透明第二型推力（Transparent Type-2 Nudge）：

Stage 1：把選項推到第一層

  • 絕不使用誘導點「全部同意」的暗黑模式（Dark Patterns）。
  • 把「了解我的學習資料如何被使用」按鈕放在與「開始使用」同等顯眼的第一層位置。
  • 實證效果：僅憑曝光與位置效應即可讓 48.81%–64.13% 使用者主動點開檢視。

Stage 2：混合式隱私量表（Hybrid Nudge）

  • 結合視覺化風險燈號（紅／綠量表）＋白話條列說明（是否加密、是否用於模型訓練或分享第三方）。
  • 登門檻效應（Foot-in-the-door）：第一階段點開過資訊的學生，第二階段低隱私方案採用率驟降至 1.64%–5.36%。
  • 進階延伸：針對直覺型年輕學生，可整合個人化隱私助理（PPA）動態提醒。

05 快速驗證與評估方法 08 / 09

如何「快速且嚴謹」地驗證你的教育 AI 工具？

驗證階段 快速工具與方法 能幫你回答什麼問題？
1. 寫程式前（原型期） 點擊原型（Click-Dummy）／情境影片模擬 ＋ GPT-4o 預實驗檢驗 先用靜態原型或影片測試介面流程與 Prompt 語氣差異，確認操弄有效再投入工程開發（Klütsch et al., 2026; Lee et al., 2027）。
2. 體驗與同理心（使用後） SUS 易用性量表 ＋ PETS 科技同理心量表 ／ RoSAS 檢驗工具是否「既好操作（如 EmotiStage SUS 81.35）」又「讓學生覺得被理解與溫暖（PETS 78.37 / RoSAS）」（Wang et al., 2026; Lee et al., 2027）。
3. 學習與覺察改變（前後測） S-DERS（當下覺察／清晰度） ＋ 自由列舉（Free-Listing） ＋ PANAS 捕捉單堂課 30–50 分鐘前後，學生的情緒或概念顆粒度是否真的變細膩（Wang et al., 2026; Kober et al., 2026）。
4. 客觀行為與統計修正 VADER 情感分析 ＋ Heckman / 貝氏邏輯迴歸 客觀檢查 AI 對話語氣是否過冷，並修正「只有積極學生才試用工具」的樣本選擇偏誤（Mourelatos & Liontou, 2026; Klütsch et al., 2026）。

06 行動檢核表 09 / 09

打造教育 AI 工具的 5 步快速檢核清單

設計與架構檢核

  • ① 拆解任務與對象：工具是給發想還是步驟執行？是否照顧到低自信／直覺型學生？
  • ② Multi-Agent 模組化：對話引導限制「每輪一問」，用 JSON 串接生成模組。
  • ③ 切分控制權邊界：讓學生調高階意義參數，繁瑣生成交給 AI。
  • ④ 語氣與外觀校準：依任務切換 Convergence / Maintenance；用風格化外觀避開恐怖谷。
  • ⑤ 透明揭露與隱私推力：明確標示 AI 身分，並採用「第一層按鈕＋視覺化說明」兩階段知情設計。

本週即可執行的下一步

  • 用 Click-Dummy 或 2 支短情境對話腳本，找 5 位同學做小規模前測。
  • 用 GPT-4o 當預實驗檢查員，驗證你的「發想語氣」與「執行語氣」Prompt 是否有明顯區隔。
  • 準備一份 10 題 SUS ＋ 簡短前後測 Free-Listing，在課堂 20 分鐘試用後立刻收集回饋。
核心心法：快速打造教育 AI 的關鍵不在於模型多大，而在於用 HCI 實證把「人、任務、控制權與透明度」對齊。
